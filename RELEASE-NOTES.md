# Mafia II Azerbaijani Patch v1.0.0

## Quraşdırma

`Mafia-II-Azerbaijani-Patch-Setup-1.0.0.exe` faylını yüklə, oyunu bağla, quraşdırıcıda `mafia2.exe` və ya oyun qovluğunu seç və **Install Azerbaijani patch** düyməsinə bas. Oyunun dilini **English** saxla.

## Included

- A single offline Windows installer with game-file and folder selection.
- Azerbaijani menus, objectives, tutorials and dialogue subtitles: all 10,166 entries in the identified base-game text corpus accounted for.
- Azerbaijani character support, including Əə, Ğğ, Şş and İı.
- Compatibility checks, original backups, interrupted-install recovery and a restore option.
- SHA-256 checksums and open installer source.

Targets **Mafia II Classic PC**, using matching English archive files. **Definitive Edition is not supported.** DLC, artwork, voices and save files are untouched. The installer supplies patch deltas only; players must own compatible game files. The earlier manual patch should be restored to English before using this installer.

Installation/restore and archive-integrity tests passed. Full playthrough and independent native-speaker review are still outstanding. See the README for compatibility details and report problems through Issues.
